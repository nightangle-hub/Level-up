Level Up prizes v6

This is the complete app built from Level-Up-app-prizes-v5.zip. Keep all files together and use the same browser and app location to retain existing records. This review release has not been deployed to the live site.

Six rare candidates
The catalogue adds r01 through r06 with original artwork at assets/prizes/r01.png through r06.png. The three creature scenes are rare milestone candidates. The other three scenes are rare normal candidates. Each scene has its own name, colour and design. The three creatures also have original names and designs, listed in PRIZES-VARIETY.txt.

Saved draws and slots
The candidate pool now contains 63 items. The schedule remains at 55 slots through 10,000 XP. Existing drawn prizes and seen receipts remain fixed. New candidates participate only when a remaining eligible slot is drawn. A completed saved gallery is not rerolled. XP rules, levels, storage keys and the first prize are unchanged.

Preserved app behaviour
The 26 existing scene entries and their pictures, the 200 XP example, Appearance files and photos, floating companion and dragging, companion corner animation, Today backgrounds, preference schema and backup implementation are byte identical to v5. Only the catalogue additions, service worker cache and documentation changed. The new images are static PNGs with the same 1448 x 1086 dimensions as existing art.

Today and backups
Use this and Use on Today work through the existing controls. Today retains its existing dark overlay and readable card surfaces. Old preferences and backups still load, and the existing export and import preserve new choices as well. Use v6 or later to restore a backup containing the new r01 through r06 IDs.

Cache and review files
The service worker cache name ends in prizes-v6, with all six new PNGs added to the cache list. PRIZES-FILES.txt lists every changed or added file. PRIZES-TESTS.txt records all requested PASS or FAIL checks. PRIZES-VARIETY.txt documents subject, time, colour and creature differences, including the revised late dusk tea garden.

Artwork method
The built-in image generation tool created the six pictures. All were generated at the required dimensions, so none required resizing. One targeted image edit removed an eye-like dot from Swaypuff to keep it faceless. The prompt set and optional art review sheet are provided separately with the review deliverables.
